# Historical Stage1 Lean artifacts

The Lean files in this directory are pre-v2 proof and audit artifacts. Embedded
references to retired files such as `Docs/Stage1_Blueprint.md` record the public
surface that existed when those artifacts were authored; they are provenance,
not current write targets or task-state authority.

`Docs/Stage1_Blueprint_v2.md` is the sole current Stage1 requirements, ordering,
and `[ ]` / `[_]` / `[x]` state source. Do not mechanically rewrite embedded
historical path literals: issue a new v2-bound artifact with fresh content
bindings when one of these files is migrated.
