# THM-M-0723 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
"polynomial hierarchy". The source inventory supplies only the gloss "hierarchical structure of
complexity classes", attributes it to Larry Stockmeyer, and dates it to 1976. That identifies a
topic, not a theorem.

Several materially different claims fit the gloss: the definition of the hierarchy, quantified
characterizations of its levels, containments between adjacent levels and PSPACE, and conditional
collapse theorems. Strictness of the hierarchy is not known unconditionally. Selecting one of
these claims without a pinpoint source would substitute mathematics for the repository target.

The intake therefore freezes the ambiguity and exclusion boundary rather than a proposition. The
root remains `[H3, M4, R4]`. A pinned Lean probe confirms that mathlib's formal-language carrier is
available, but the bounded search found no polynomial-hierarchy API. The probe is neither a target
statement nor proof. Exact commands and results are recorded in `validation.md`.
