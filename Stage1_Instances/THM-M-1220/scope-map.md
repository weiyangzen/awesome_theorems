# Scope map

## Preserved source scope

- Subject: nonlinear wave equations (`NLW`), with no displayed equation.
- Property: well-posedness, without a specified Hadamard formulation or topology.
- Attribution and period: many mathematicians, twentieth century.
- Repository category: differential equations / partial differential equations.

This is all the mathematical scope fixed by the available repository source.

## Decisions required before statement freeze

The statement phase must identify a primary theorem and freeze: the precise PDE and sign/form of
the nonlinearity; spacetime domain, dimension, scalar field, and time interval; initial/boundary
data; solution concept; function spaces and regularity; local, global, maximal-lifespan, or
small-data regime; existence, uniqueness class, continuous/Lipschitz dependence, persistence and
blow-up alternative conclusions; focusing/defocusing and criticality restrictions; constants; and
endpoint or degenerate cases.

It must also distinguish classical well-posedness from weak-solution existence, scattering,
stability, and conditional continuation, none of which alone is synonymous with the source phrase.

## Explicit exclusions

- Substituting the linear wave equation or an abstract evolution problem.
- Selecting a cubic, semilinear, energy-critical, or defocusing NLW only because its API is handy.
- Treating the neighboring Segal, Ginibre-Velo, Shatah-Struwe, or Tao entries as this target.
- Treating existence alone as well-posedness without the intended uniqueness and dependence terms.
- Treating `已验证` as proof evidence or inventing a Lean proposition before source identification.
