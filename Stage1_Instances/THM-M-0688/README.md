# THM-M-0688 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "ordinal
notation". The source inventory supplies only the gloss "notation systems for large ordinals", a
collective attribution, and the period "20th century". This describes a subject, not a proposition.

The phrase does not select an ordinal bound, a syntax, a semantics, or a property to prove. For
example, Cantor normal-form notations below epsilon-zero, Veblen-style notations up to Gamma-zero,
and stronger proof-theoretic notation systems have different constructors, comparison relations,
fundamental sequences, and correctness or well-foundedness claims. Choosing one would silently
substitute a new theorem for the repository target.

The intake therefore freezes the ambiguity and exclusion boundary rather than inventing a claim.
The root remains `[H3, M4, R4]`. A pinned Lean probe confirms that mathlib exposes an ordinal
notation implementation below epsilon-zero and related Veblen APIs; those APIs are candidate
encoding ingredients, not the canonical statement or a proof of this target. Exact commands and
results are recorded in `validation.md`.
