# THM-M-0375 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "restriction
theorem". The inventory gloss says only "restriction of the Fourier transform to a surface",
attributes the item to Elias Stein, and gives 1986. It supplies no surface, dimension, exponent
range, function class, measure, transform normalization, estimate, or pinpoint source.

That wording does not select one theorem. It may refer to the Stein-Tomas sphere restriction
theorem, another restriction theorem for a specified curved hypersurface, or the general Fourier
restriction problem. The ambiguity is material: the repository immediately follows this entry with
a separate, partially solved "Fourier restriction conjecture" having the same gloss. Choosing a
convenient sphere estimate now would substitute a narrower theorem for the recorded target.

The intake therefore freezes the scope boundary and source gaps, not a proposition. The root remains
`[H3, M4, R4]`. A pinned Lean probe confirms that mathlib has Fourier integrals, sphere measures,
measure transport/restriction, and extended `Lp` seminorms that may support a later encoding. The
probe is neither the target statement nor proof evidence. Exact commands are in `validation.md`.
