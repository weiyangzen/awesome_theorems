# THM-M-0801 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
"indescribable cardinal". The source inventory supplies only the gloss "properties of
indescribable cardinals", a collective attribution, the period "20th century", and an untrusted
`verified` label. It does not state a proposition.

Indescribability is a family of reflection properties, not one theorem. A source must at least
select a syntactic class such as `Pi^m_n` or `Sigma^m_n`, the allowed higher-order variables and
parameters, the structure over `V_kappa`, and the reflected rank `V_alpha`. It must then say whether
the target is the definition, a characterization (for example a relationship with weak
compactness), an implication between levels, or another property. "Totally indescribable" is yet
another materially stronger reading.

Selecting any such claim from the title would substitute invented mathematics for the repository
record. This intake freezes that ambiguity and its exclusions rather than inventing a canonical
Lean theorem. The root remains `[H3, M4, R4]`. A pinned Lean probe checks only nearby cardinal and
first-order syntax APIs; it does not encode the cumulative hierarchy or indescribability and
receives no statement or proof credit. Exact commands and results are in `validation.md`.
