# THM-M-0110 obligation tree

Item: `S56-M-0110-OBLIGATION_TREE`

Registry v1 freezes 23 root-relevant obligations against the exact statement
and bounded anchor audit. The machine-readable authorities are
`obligation-registry.json` and `typed-graphs.json`. No obligation is accepted
closed by this phase.

## Proof route

```text
M0110-ROOT exact KodairaVanishingTarget
`-- M0110-T-ASSEMBLE checked conditional root assembly
    |-- M0110-S-SEMANTIC future native geometric witness package
    `-- M0110-T-VANISHING substantive vanishing argument consuming that witness
```

The Lean module checks only this conditional composition. The detailed
algebraic and analytic routes remain unverified architecture plans. They are
not proof premises in the checked proof graph. In particular, the two route
candidates are alternatives recorded with expository edges; the graph does
not incorrectly require both. The weak THM-M-0118 shared-module group is
audited as non-reusable in `dependency-reuse-ledger.json`.

## Node ledger

<a id="m0110-root"></a>
### M0110-ROOT

The exact expression-fingerprinted target in `Statement.lean`. It remains
`H1/M3/R3`; no unconditional proof body exists or is claimed.

<a id="m0110-s-target"></a>
### M0110-S-TARGET

Freezes the universe, characteristic-zero field, data package, ordered
hypotheses, positive degree, and concrete `Sheaf.H` conclusion.

<a id="m0110-s-boundary"></a>
### M0110-S-BOUNDARY

Retains every hypothesis and the exclusion of degree zero. The statement
mutations check expression differences; they do not close source fidelity.

<a id="m0110-s-semantic"></a>
### M0110-S-SEMANTIC

Owns the first machine blocker. The current proposition labels do not relate
projectivity, canonical/dualizing roles, ampleness, invertibility, or tensor
identity to the actual objects. `NativeSemanticTransportPackage` is only a
conditional signature slot. A later registry version must replace it with
concrete native witnesses and checked transports.

<a id="m0110-s-cohomology"></a>
### M0110-S-COHOMOLOGY

Requires an exact degree-preserving comparison between the proof route's
cohomology and the concrete `Sheaf.H` carrier. A different or abstract
cohomology family cannot substitute for it.

<a id="m0110-s-foundation"></a>
### M0110-S-FOUNDATION

Owns axiom, TCB, import, compiled-artifact, and no-oracle acceptance for the
eventual terminal proof objects. The conditional harness currently reports

<a id="m0110-n-algebraic"></a>
### M0110-N-ALGEBRAIC

Must normalize native projective morphisms, canonical/dualizing sheaves,
ample invertible sheaves, and tensor products to the frozen carriers.

<a id="m0110-n-analytic"></a>
### M0110-N-ANALYTIC

An analytic route over an arbitrary characteristic-zero field must first
descend to finite-type data, embed into `Complex`, apply the analytic/GAGA
comparison, and transport the result back by checked base change.

<a id="m0110-b-route"></a>
### M0110-B-ROUTE

A future versioned decision must select one complete algebraic or analytic
route and supply its checked return transport. Neither candidate currently
receives closure credit.

<a id="m0110-l-serre-duality"></a>
### M0110-L-SERRE-DUALITY

Requires exact dualizing/canonical identification, tensor conventions, and
cohomological indexing on the frozen scheme and coefficient objects.

<a id="m0110-l-serre-vanishing"></a>
### M0110-L-SERRE-VANISHING

Requires a genuine algebraic Kodaira engine. Ordinary Serre vanishing only

<a id="m0110-l-dolbeault"></a>

<a id="m0110-c-algebraic"></a>

<a id="m0110-c-analytic"></a>

The minimal open proof cut is `M0110-S-SEMANTIC` plus
`M0110-T-VANISHING`. Source, provenance, trust, readability, hermetic replay,
independent validation, `AUDIT-Z`, and `THEOREM-Z` also remain open. The root
vector stays `H1/M3/R3`.
