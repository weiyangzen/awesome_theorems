# THM-M-1346 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
`稳定流形定理` (stable manifold theorem). The repository supplies only the gloss
`双曲平衡点的稳定与不稳定流形` (stable and unstable manifolds of a hyperbolic equilibrium),
the attribution "many mathematicians," and the twentieth century. Those data identify a
dynamical-systems theorem family, but they do not form one truth-valued proposition.

The name can refer to a local theorem for a continuous-time vector field, a theorem for a
diffeomorphism or time-one map, the global stable/unstable sets assembled from local leaves, a
Hadamard-Perron theorem in Banach spaces, a normally hyperbolic invariant-manifold theorem, or a
nonuniform/Pesin theorem. Even in the finite-dimensional ODE reading, the gloss leaves regularity,
the definition of hyperbolicity, local versus global scope, embedded versus immersed manifold,
tangency, invariance, exponential estimates, dimensions, uniqueness, and every boundary case open.

Gerald Teschl's *Ordinary Differential Equations and Dynamical Systems*, Section 9.2, was inspected
as an authoritative discovery source. Its Theorems 9.3-9.5 distinguish an exponential-rate graph
theorem, a stable/unstable manifold theorem that does not itself assume hyperbolicity, and a
hyperbolic identification with stable/unstable sets. The catalog does not cite or select one of
these formulations, so none is accepted as the canonical source statement at intake.
