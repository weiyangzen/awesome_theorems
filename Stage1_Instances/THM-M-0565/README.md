# THM-M-0565 rev-5.6 intake

This directory is the `planned` intake for Stiefel-Whitney characteristic classes. The repository
source says only "mod-2 characteristic classes of real vector bundles." That denotes a family of
constructions and results, not a proposition with fixed binders and conclusion. This intake keeps
that ambiguity visible rather than silently substituting the existence, uniqueness, naturality,
Whitney-sum, normalization, or tangent-bundle obstruction theorem.

The provisional root vector is `[H4, M4, R4]`. The scope map records the subject boundary and the
statement choices that remain open. The source crosswalk records exactly what the repository source
does and does not support. No Lean theorem, proof state, audit completion, or theorem completion is
claimed. Exact intake checks and their results are recorded in `validation.md`.
