# THM-M-0805 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "axiom of
determinacy and descriptive set theory". The only source gloss is "AD and properties of projective
sets". That names a research area and a family of consequences, not one theorem.

The record does not say whether AD means determinacy for all Gale-Stewart games on naturals, which
projective pointclass or level is quantified over, or which property is asserted. Regularity,
uniformization, scales, closure properties, and determinacy are materially different conclusions;
their needed background axioms also differ. Selecting one would substitute invented mathematics
for the repository target.

This intake therefore freezes the ambiguity and scope boundary, not a proposition. The root remains
`[H3, M4, R4]`. A pinned Lean probe confirms only that mathlib exposes descriptive trees, analytic
sets, Polish spaces, and measurable sets as possible encoding ingredients. It is not a theorem
statement or proof. Exact commands and results are recorded in `validation.md`.
