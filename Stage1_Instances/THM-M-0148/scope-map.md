# Scope Map

| Surface | Intake disposition |
|---|---|
| Repository slogan | In scope as provenance, not as an exact theorem |
| Higher-dimensional birational classification | Programme umbrella; must be narrowed |
| Scheme and rational-map object boundary | Candidate infrastructure only |
| Cone and contraction theorems | Candidate future named branches |
| Existence of flips | Candidate future named branch; assumptions must be fixed |
| Termination of flips | Separate and potentially open branch; never silently assumed |
| Minimal-model existence | Candidate future branch, dimension/characteristic dependent |
| Mori fibre-space alternative | Candidate future output branch |
| Abundance/canonical model claims | Excluded unless explicitly selected and sourced |
| Legacy parameterized `StatementShape` | Excluded as canonical target; it abstracts missing mathematics |

The exact domain, universes, ordered binders, hypotheses, conclusion, and
degenerate cases remain open. Consequently statement fingerprinting,
mutation tests, obligation denominators, and proof search are not eligible yet.
