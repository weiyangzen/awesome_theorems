# THM-M-0538 rev-5.6 intake

This directory is the `planned` intake for the Eilenberg-Steenrod axioms. The repository record
names an axiom system for homology theory, not a single theorem that can truthfully be assigned a
proof before its intended assertion is selected. The intake therefore freezes the topic and the
principal classical components while leaving the exact proposition for the statement phase.

The main source ambiguity is whether the target is (a) the definition/package of an ordinary
homology theory satisfying the axioms, (b) the theorem that singular homology satisfies those
axioms, or (c) a characterization or uniqueness theorem for such theories. These are not
interchangeable. Reduced versus unreduced theories, category of pairs, coefficients, dimension and
additivity conventions, and the natural connecting maps are also open.

The provisional root vector is `[H2, M4, R4]`: the repository wording is too underspecified to map
to a stable proposition, no canonical Lean expression is claimed, and no readable proof exists.
The scope map, source crosswalk, and open task DAG record the exact downstream decisions. This
intake grants no statement, proof, audit, or theorem-completion credit.
