# Scope map

## Included topic boundary

- An imaginary quadratic number field, with its order specified where nonmaximal orders matter.
- A precisely named class field: Hilbert, ring, ray, or another source-defined family.
- Source-specified modular functions and CM special values used as generators.
- An exact field-generation equality or reciprocity/classification conclusion.
- All conductor, discriminant, integrality, unit, and roots-of-unity qualifications in the source.

## Ambiguities to resolve at statement freeze

The repository gloss admits materially different theorems. A source might assert that a singular
modulus generates a Hilbert class field, that modular-function values generate ring or ray class
fields, or a broader explicit class-field classification. These differ in their quantified fields,
orders, conductors, functions, bases, and conclusions. The title also historically names a program
rather than one universally fixed formula.

The statement phase must freeze the ordered binders and decide at least: maximal or nonmaximal
order; Hilbert, ring, or ray class field; the modular function and CM point; generation over the
quadratic field or another field; and all discriminant, conductor, unit, and integrality cases.

## Explicit exclusions

- Hilbert's twelfth problem as a substitute; its general real-quadratic part is not this theorem.
- The bare existence theorem of class field theory without explicit CM generators.
- General complex multiplication theory, CM-field structure, or a class-number theorem alone.
- A single numerical discriminant or computed class polynomial substituted for the uniform claim.
- An assumed "is generated by" hypothesis followed by a tautological conclusion.
- The repository label `已验证` as human-proof or machine-proof evidence.

No canonical Lean target is frozen at intake because the source record does not identify one.
