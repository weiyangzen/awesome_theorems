# THM-M-0383 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "Bourgain
restriction theorem". The source inventory supplies only the gloss "higher-dimensional Fourier
restriction theorem", the attribution Jean Bourgain, and the year 1991. That wording does not
identify a unique theorem, paper, dimension, hypersurface, exponent range, or estimate.

Fourier restriction has several materially different statements: continuous restriction or
extension estimates for a sphere or paraboloid, local rather than global estimates, discrete
restriction estimates, and particular improvements in specified dimensions and exponent ranges.
Calling any one of these the target without a source passage would substitute invented mathematics
for the repository record.

The intake therefore freezes the ambiguity and exclusion boundary rather than a proposition. The
root remains `[H3, M4, R4]`. A pinned Lean probe confirms that Fourier transforms, `L^p` predicates,
Euclidean spheres, restricted measures, and extended norms are available as encoding ingredients;
it is not a theorem statement or proof. Exact commands and results are in `validation.md`.
