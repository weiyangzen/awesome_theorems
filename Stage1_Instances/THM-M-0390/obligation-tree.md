exhaustive, representation-neutral split on `q = 2`; under `q != 2` it splits on `p = 2`. The Lean

root. This checks the split and root recomposition, not any mathematical branch.

The source audit has not yet supplied theorem/page-level mappings for these transitions. Accordingly
the nodes remain `H3`, `M3/M4`, and `R4`; the package names are architecture derived from the known
proof route and the legacy discovery skeleton, not claims of source acceptance.

## Trust boundary

contains no asserted branch theorem. Its narrow elaboration checks the logical case split. It does
not inventory a future proof's imports, axioms, terminal bodies, computation, native code, or
release TCB. `THM-M-0390-X-TRUST` therefore remains a required root-relevant obligation.
