# THM-M-0507 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
"Hardy-Littlewood circle method". The source inventory describes it only as a fundamental method
of additive number theory. A method is not by itself a proposition: the record supplies no
representation problem, asymptotic formula, variables, hypotheses, or conclusion.

The circle method supports materially different theorem families, including Waring-type
representation asymptotics, additive prime problems, and partition asymptotics. Choosing one would
substitute new mathematics for the repository record. The intake therefore freezes this ambiguity
and its exclusion boundary. The root remains `[H3, M4, R4]`.

A narrow pinned Lean probe confirms that mathlib provides the additive circle, its normalized Haar
measure, Fourier characters, and Fourier coefficients. Those are possible encoding ingredients,
not an exact statement or proof. Exact validation commands and results are in `validation.md`.
