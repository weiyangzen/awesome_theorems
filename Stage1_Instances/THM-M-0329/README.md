repository source gives only the gloss "existence and uniqueness of the solution of a variational
problem" and does not state the scalar field, spaces, coercivity convention, right-hand-side

form represents every continuous linear functional by a unique vector. Pinned mathlib contains a
closely related real-Hilbert-space formulation as a continuous linear equivalence. That declaration
is an encoding candidate, not yet the frozen canonical target: the source wording has not been
pinpointed and the argument order/inner-product representation still needs a checked crosswalk.

The provisional root is `[H1, M3, R4]`. This intake gives no proof credit and claims neither audit
completion nor theorem completion. Exact commands and results are recorded in `validation.md`.
