# THM-M-1554 rev-5.6 intake

This directory is the `planned` intake for a Bäcklund-transformation theorem. The repository's
source phrase, "a transformation of integrable systems", names a broad construction family rather
than a proposition. The intake therefore bounds the intended result to an auto-Bäcklund theorem
for one explicitly selected integrable PDE: the first-order transformation relations take a
sufficiently regular solution to another solution, and their compatibility recovers the nonlinear
equation.

The PDE is not silently chosen here. Sine-Gordon, KdV, and other equations have different
transformations, parameter restrictions, signs, scalings, regularity assumptions, and local/global
claims. Those choices require an immutable, pinpointed mathematical source and independent review
in the statement phase. Until then the provisional root vector is `[H3, M4, R4]`.

The scope map records the admissible theorem shape and exclusions. The source crosswalk ties every
claim presently available to repository files and identifies the missing source decision. The open
task DAG preserves all downstream rev-5.6 work. No formal statement, kernel proof, source-fidelity
approval, audit completion, or theorem completion is claimed.
