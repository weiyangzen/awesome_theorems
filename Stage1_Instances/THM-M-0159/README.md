# THM-M-0159 rev-5.6 intake

This directory is the `planned` intake dossier for the Gauss-Codazzi-Mainardi equations. The
repository gloss calls them compatibility conditions for the fundamental forms of a surface. This
intake freezes the necessity direction for a smooth immersed surface in Euclidean three-space:
the induced metric and second fundamental form obey the Gauss curvature equation and the Codazzi
symmetry equation.

The converse existence-and-uniqueness result is the fundamental theorem of surface theory and is
not silently included here. Higher-codimension, pseudo-Riemannian, abstract hypersurface, and
coordinate-only variants are alternate formulations requiring checked transports, not replacements
for the root.

The provisional root vector is `[H1, M4, R4]`. The exact source edition, theorem/page, conventions,
Lean binders, and concrete differential-geometric APIs remain open. No source acceptance, exact
Lean expression, proof credit, audit completion, or theorem completion is claimed. The scope map,
source crosswalk, and open task DAG record the downstream work; exact intake checks are in
`validation.md`.
