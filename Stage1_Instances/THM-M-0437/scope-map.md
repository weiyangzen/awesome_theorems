# Scope map

| Surface | In scope | Intake boundary |
|---|---|---|
| Datum | Shimura datum `(G,X)` of Hodge type | Exact group/category encoding and universes open |
| Hodge condition | embedding into a Siegel Shimura datum | Faithfulness, symplectic representation, and tensor formulation must match the selected source |
| Level | compact open `K` with all smallness hypotheses | Neatness and connected/full quotient variant open |
| Analytic object | the relevant double quotient describing complex points | Quotient conventions and component action open |
| Field | reflex field `E(G,X)` | Lean number-field representation open |
| Root construction | algebraic Shimura variety and canonical model over the reflex field | Exact universal/descent characterization awaits source pinning |
| Excluded extension | integral models, good reduction, and moduli representability | Not silently included in the root |

The target cannot be discharged by packaging unproved `Prop` fields. The datum,
level, variety, base change, complex-points identification, and descent law must
be connected by typed constructions or imported checked theorems. Trivial
groups or empty moduli cannot be used to replace the source's universal claim.
