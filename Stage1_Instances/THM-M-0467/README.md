# THM-M-0467 rev-5.6 intake

This directory is the `planned` intake for Raynaud's theorem, understood from the repository's
Stage0 description as Raynaud's proof of the Manin-Mumford conjecture. The intended scope is the
characteristic-zero torsion-point theorem for a closed subvariety of an abelian variety, not an
unrelated theorem bearing Raynaud's name.

The exact historical formulation, hypotheses, and equivalence between the closure and finite-union
forms still require primary-source inspection. Accordingly the provisional root vector is
`[H2, M4, R4]`. No exact Lean target, source fidelity, proof closure, audit completion, or theorem
completion is claimed. The scope map and crosswalk make these open decisions explicit; the task DAG
keeps every later rev-5.6 phase open.
