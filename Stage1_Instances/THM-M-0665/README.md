# THM-M-0665 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the Pila-Wilkie theorem. The
repository gloss, "rational points in o-minimal structures", is resolved provisionally to the
first quantitative counting theorem: if `X` is a definable subset of real affine space, then the
rational points of bounded affine height in `X` outside its algebraic part number at most
`c * T^epsilon` for every positive `epsilon`.

different target ID, have not been re-admitted here, and supply no statement or proof credit.
