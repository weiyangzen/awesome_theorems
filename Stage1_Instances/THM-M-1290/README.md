# THM-M-1290 rev-5.6 intake

This directory is the `planned` intake for the Brezis-Nirenberg problem. The intended claim concerns
existence and nonexistence of positive Dirichlet solutions of the critical Sobolev exponent equation
on a bounded domain. The name denotes a theorem family rather than one proposition: dimension,
domain regularity, the parameter range, and the special three-dimensional threshold must be selected
from an inspected primary source before an exact Lean statement is frozen.

The Stage0 label `已验证` is untrusted metadata and supplies no proof credit. This intake claims only
the provisional vector `[H2, M4, R4]`; it claims no exact Lean expression, source-complete proof,
kernel closure, audit completion, or theorem completion. The scope map, source crosswalk, and open
task DAG make those boundaries executable.
