# THM-M-0795 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "forcing
axioms". The source inventory supplies only the plural gloss "various forcing axioms and their
applications", a collective attribution, and the period "20th century". It does not select one
axiom, one axiom schema, a consistency theorem, or an application.

Forcing axioms form a family rather than a single interchangeable proposition. Martin's Axiom,
the Proper Forcing Axiom, bounded variants, and Martin's Maximum differ in the permitted forcing
class, dense-family bound, base theory, and consistency strength. An "application" would instead
be a conditional theorem with a particular forcing axiom as a hypothesis. Choosing any member or
consequence without a source would substitute new mathematics for the received record.

The intake therefore freezes this ambiguity and its exclusions rather than inventing a canonical
claim. The root remains `[H3, M4, R4]`. A pinned Lean probe confirms only that mathlib exposes
generic partial-order, filter, density, and cardinal ingredients from which a source-selected
encoding might later be built. It is neither a forcing axiom nor a proof. Exact commands and
results are recorded in `validation.md`.
