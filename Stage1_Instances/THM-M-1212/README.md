# THM-M-1212 rev-5.6 intake

This directory is the `planned` intake for the nonlinear Schrodinger equation well-posedness
theorem family. The repository's source phrase is broad rather than a single mathematical theorem:
it does not fix an equation, dimension, exponent, data space, or solution concept. This intake
therefore freezes the intended family and the decisions required for an exact statement; it does
not invent a narrower result.

The Stage0 `verified` label is untrusted discovery metadata and gives no proof credit. The
provisional root vector is `[H2, M4, R4]`. No exact source theorem, canonical Lean expression,
kernel proof, audit completion, or theorem completion is claimed.

The scope map and source-statement crosswalk preserve the ambiguity explicitly. The dependent
statement task must select and justify one primary theorem that faithfully represents the recorded
well-posedness family before formalization can proceed. Exact intake checks and their limits are in
`validation.md`.
