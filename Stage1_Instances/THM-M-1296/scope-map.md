# Scope map

## Provisional included claim

- A bounded sequence in a Sobolev or homogeneous Sobolev space selected from the primary source.
- Passage to a subsequence and extraction of countably many profiles.
- Action on each profile by the source's translation, dilation, time-translation, or other symmetry
  parameters, with pairwise asymptotic orthogonality.
- Reconstruction by finitely many profiles plus a remainder, norm or energy decoupling, and a
  source-specified iterated-limit smallness statement for the remainder.

## Decisions required at statement freeze

The statement phase must select a single primary theorem and freeze the ambient dimension, scalar
field, homogeneous versus inhomogeneous space, exponent range, sequence indexing, subsequence,
symmetry group and normalization, profile enumeration, parameter orthogonality, topology of profile
convergence, exact Pythagorean or inequality form, remainder norm, and the order of limits. It must
also settle zero profiles, finite decompositions, vanishing sequences, endpoint exponents, and all
measurability or representative conventions.

## Explicit exclusions

- An arbitrary Hilbert-space orthogonal decomposition or Fourier series.
- Nonlinear soliton resolution, bubble-tree convergence, or concentration compactness alone as a
  substitute for the selected linear profile theorem.
- A theorem that merely assumes the profiles, decoupling, or small remainder as structure fields.
- The repository label `已验证` as source or kernel evidence.

No Lean target is frozen at intake. A later target must expose the actual function spaces,
symmetry actions, subsequence, parameter divergence, decomposition, and remainder estimates.
