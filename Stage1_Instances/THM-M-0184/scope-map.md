# Scope map

| Surface | In scope | Intake boundary |
|---|---|---|
| Base geometry | compact oriented Riemannian smooth four-manifold | closed versus boundary, regularity class, and metric genericity must follow the selected source theorem |
| Gauge datum | principal bundle with compact structure group, connection space, gauge action | `SU(2)`/`SO(3)`, Sobolev completions, and based/full gauge group unresolved |
| Equation | curvature condition `F_A^+ = 0`, equivalently anti-self-duality under fixed conventions | Hodge-star, orientation, sign, and normalization conventions unresolved |
| Moduli object | ASD solutions modulo gauge, with reducible and irreducible loci distinguished | no quotient, topology, or smooth structure is credited yet |
| Local result | elliptic deformation complex, regularity/transversality, expected dimension | exact index formula and hypotheses require a theorem-level source pinpoint |
| Global result | orientation and Uhlenbeck compactification/bubbling strata where present in the selected theorem | compactification is not silently identified with ordinary compactness |
| Lean surface | concrete mathlib manifolds plus future gauge-theory interfaces | historical abstract structures are discovery inventory only |

The target excludes Donaldson's diagonalization theorem and polynomial invariants unless source
audit establishes that one of them, rather than the moduli-space regularity family, is the intended
root. It also excludes weakening the result to the definition of anti-self-duality, existence of an
abstract orbit set, or an output structure whose substantive conclusions are assumed as fields.
