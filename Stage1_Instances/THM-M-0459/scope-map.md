# Scope map

## Frozen repository claim

- Attribution: Shou-Wu Zhang.
- Date supplied by repository metadata: 1992 (untrusted until sourced).
- Domain: curves in arithmetic geometry.
- Subject: points whose value under some height is small.

This is the maximum exact scope supported by the repository text. In particular, "small" is not
silently interpreted as height zero, bounded height, essential minimum, or a limiting sequence.

## Statement-phase decisions

Primary-source inspection must determine the kind of curve (arithmetic surface, projective curve,
or a curve embedded in an abelian variety), base field, chosen line bundle or polarization, height
normalization, quantifiers and threshold, whether the conclusion is existence, finiteness, density,
an inequality, or a lower bound, and every smoothness/regularity/genus/non-isotriviality condition.
It must also distinguish this item from the separately listed equidistribution theorem THM-M-0460.

## Exclusions

- Northcott finiteness, Bogomolov's conjecture, or equidistribution as a substitute merely because
  each mentions small points.
- A generic ordered-field inequality or an abstract predicate named `SmallHeight`.
- An assumed structure containing the desired result.
- Any exact Lean theorem before a primary-source statement resolves the ambiguity above.
