# THM-M-0957 frozen obligation architecture

## Freeze boundary

Registry version 1 freezes 45 architecture records for the exact historical epsilon-dependent
Behrend target before proof execution. Twenty-eight are required machine obligations; the remainder are
statement, imported-body, source, trust, documentation, or workflow overlays and are never counted
as independent machine proof obligations. The proof spine uses the pinned implicit construction
theorem `Behrend.bound_aux`, then requires new sharp parameter estimates. Mathlib's fixed
constant-four terminal theorem is recorded only as a checked mismatch: it is too weak at epsilon
`1` and is not a root proof child.

The entries below are architecture ledgers, not completed readable proofs. Every node remains
`[H1, M3/M4, R3]` or a non-proof overlay, every accepted evidence list is empty, and independent
source, formal, and readable review remain pending.

The proof DAG has fourteen required leaves. `T-CONSTRUCTION` and `N-INCLUSIVE-INDEX` have checked
candidate adapters but are not accepted; the other twelve leaves are unimplemented and have
ordered, explicitly unchecked proof plans. Planned non-root statement fingerprints bind the frozen
architecture record rather than a machine-extracted Lean expression. Exact package types are
ascribed by the conditional Lean certificates, but proof-phase acceptance must strengthen the
fingerprint binding before any M0 credit.
