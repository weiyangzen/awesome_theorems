# Scope map

## Included topic boundary

- A source-specified formulation of the Proper Forcing Axiom in an explicit base set theory.
- Proper partial orders, the selected order orientation, and the exact properness predicate.
- A family of dense subsets with a source-specified `aleph_1` cardinality bound.
- A filter or directed subset meeting every member of that family.
- Only a specifically named consequence if the source proves that the repository target intended it.

## Ambiguities to resolve at statement freeze

The repository phrase does not decide among these materially different targets:

1. PFA as an axiom schema/principle, formalized as a proposition over an internal model of set theory.
2. A metatheorem asserting relative consistency of PFA from a large-cardinal hypothesis.
3. A particular consequence of PFA, with PFA as a hypothesis.
4. A survey-style conjunction or collection of consequences, which is not a single proposition.

Even the first reading must fix `<= aleph_1` versus an `omega_1`-indexed family, the forcing order
orientation, the definition of dense, the filter/directed-set presentation, universe coding, and
the model of ZFC in which properness and countability are interpreted.

## Explicit exclusions

- Martin's Axiom, Martin's Maximum, bounded PFA, and forcing axioms for a narrower class as substitutes.
- Proper forcing itself, the forcing theorem, or preservation theorems as substitutes for PFA.
- Assuming a field named `pfa` and returning it by projection as a proof of PFA.
- Proving an arbitrary easy consequence of PFA when the source has not selected that consequence.
- Calling PFA a theorem of ZFC without a source and a foundation-sensitive statement.
- Treating the repository labels `已验证` or `PFA及其推论` as human-proof or kernel evidence.

No canonical Lean target is frozen at intake because the source record does not identify one.
