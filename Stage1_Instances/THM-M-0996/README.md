# THM-M-0996 rev-5.6 intake

This directory is the `planned` intake for the Gaussian isoperimetric inequality. The repository's
legacy description resolves the otherwise ambiguous Chinese title "Gaussian concentration
inequality" to the isoperimetric theorem for Gaussian measure. The intended claim compares
neighborhoods of measurable sets in finite-dimensional standard Gaussian space with half-spaces.

The exact quantile formula and boundary conventions remain statement-phase work. The provisional
root vector is `[H2, M4, R4]`; no exact Lean target, source fidelity, proof, audit completion, or
theorem completion is claimed. The scope map, crosswalk, and open task DAG make that boundary
explicit. Intake validation is recorded in `validation.md`.
