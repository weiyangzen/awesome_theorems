# THM-M-1320 rev-5.6 intake

This directory is the `planned` intake for the Li-Yau estimate. Following the Stage0 record, the
intended claim is the Li-Yau lower bound for the first positive Laplace-Beltrami eigenvalue of a
compact Riemannian manifold under nonnegative Ricci curvature, in terms of its diameter. The exact
normalization and numerical constant must be confirmed from the primary source before a Lean
statement is frozen.

The name "Li-Yau estimate" is also widely used for a parabolic gradient estimate. That result is
not silently substituted here. The source crosswalk records this ambiguity and makes resolution of
the historical theorem anchor the first statement-phase gate.

This intake claims only a dossier, scope map, crosswalk, and open downstream task DAG. Its
provisional root vector is `[H2, M4, R4]`; it claims no canonical Lean elaboration, proof, audit
completion, or theorem completion.
