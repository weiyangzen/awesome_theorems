# THM-M-1548 rev-5.6 intake

This directory is the `planned` intake for the Korteweg-de Vries equation. The source metadata
supplies only the phrase "nonlinear wave equation" and does not state a proposition. Accordingly,
the intake freezes the standard normalized equation as the subject but refuses to choose existence,
uniqueness, conservation, soliton verification, or inverse scattering as a substitute theorem.

The legacy module is discovery input only. It contains useful definitions, but its broad global
solution package and its separately selected one-soliton branch are different possible claims; the
module itself says the analytic target is unproved. They receive no rev-5.6 statement or proof
credit. The provisional root vector is `[H3, M4, R4]`.

The scope map and crosswalk make the ambiguity explicit, and the open task DAG records every later
phase. Exact intake validation is recorded in `validation.md`. No audit or theorem completion is
claimed.
