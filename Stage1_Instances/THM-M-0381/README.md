# THM-M-0381 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label "Strichartz
estimates". The inventory supplies only "space-time estimates for solutions of dispersive
equations", an attribution to Robert Strichartz, and the year 1977. It does not state one theorem.

Strichartz estimates form a family: wave, Schrodinger, Klein-Gordon, and abstract dispersive
propagators have different scaling relations; homogeneous and inhomogeneous estimates have
different inputs; local and global time, endpoint inclusion, derivative loss, geometry, and
constant dependence materially change the proposition. Selecting one variant without a pinpoint
source would substitute invented mathematics for the repository target.

The intake therefore freezes the ambiguity and exclusions rather than a canonical proposition.
The root remains `[H3, M4, R4]`. A pinned Lean probe checks only measure, `Lp`, `MemLp`, product,
and Fourier-transform APIs that could encode parts of a later statement. It is not a propagator,
Strichartz estimate, or proof. Exact commands and results are recorded in `validation.md`.
