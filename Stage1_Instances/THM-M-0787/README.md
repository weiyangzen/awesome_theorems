theorem". The only supplied gloss is "projective determinacy and large cardinals". That phrase
names a research connection, not one proposition: it does not specify a direction of implication,
the number or kind of large cardinals, an ambient set theory, or whether the intended result is an
equiconsistency, an inner-model theorem, or an outright implication.

The intake therefore freezes this ambiguity and the substitution boundary rather than inventing a
theorem. The root remains `[H3, M4, R4]`. A pinned Lean probe confirms only that mathlib's basic
cardinal and set encodings elaborate. It neither encodes projective determinacy nor a
Woodin cardinal and receives no statement or proof credit. Exact commands and results are recorded
in `validation.md`.
