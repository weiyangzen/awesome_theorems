# THM-M-0598 rev-5.6 intake

This directory is the fail-closed `planned` intake for the repository label "Morse theory". The
source inventory supplies only the broad description "the topology of manifolds and the critical
points of smooth functions". Morse theory is a family of results, not by itself one uniquely
quantified proposition. This intake therefore freezes that literal scope and a provisional central
claim family, while leaving selection of the exact sourced root to the statement phase.

The provisional family is the handle-attachment/sublevel-set theorem for a Morse function: crossing
one nondegenerate critical value changes a sublevel set by attachment of a handle whose index is the
critical point's Morse index, while an interval containing no critical value does not change the
diffeomorphism type. Compactness, boundary, properness, critical-value separation, and endpoint
conventions must come from an inspected source and are not silently supplied here.

The provisional root vector is `[H1, M4, R4]`. There is no canonical Lean expression, source-complete
`H0`, kernel proof, audit completion, or theorem completion. The scope map, source crosswalk, and open
task DAG preserve the unresolved choices; `validation.md` records intake-only checks.
