# THM-M-1322 rev-5.6 intake

This directory is the `planned` intake for Kroger's Neumann-Laplacian eigenvalue theorem. The
repository's phrase "upper bound for the first eigenvalue" is not precise enough to select a
unique theorem: Kroger's 1992 paper is commonly associated with upper bounds for the sequence of
Neumann eigenvalues, while indexing conventions distinguish the zero eigenvalue from the first
positive eigenvalue.

Accordingly, this intake freezes the subject and the ambiguity, not a formula. The statement phase
must inspect the primary paper and identify the exact theorem, domain assumptions, eigenvalue
indexing, and constants before producing Lean. The provisional root vector is `[H3, M4, R4]`; no
source fidelity, elaborated statement, proof, audit completion, or theorem completion is claimed.
