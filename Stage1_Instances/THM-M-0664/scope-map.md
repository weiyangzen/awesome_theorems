# Scope map

## Provisional included claim

- An o-minimal first-order expansion of a dense linear order, with the source's exact parameter and
  endpoint conventions still to be selected.
- A natural arity and a finite family of definable subsets of the corresponding Cartesian power.
- A finite partition into recursively cylindrical cells, compatible with every input set: every
  cell lies wholly inside or wholly outside each set.
- The general all-dimensions structural theorem, rather than merely the unary definition of
  o-minimality.

This scope identifies a theorem family for source review. It is not an exact statement.

## Statement-phase decisions

Primary-source inspection must freeze the source edition, theorem and page, ambient order
assumptions, named versus arbitrary parameters, tuple encoding, the induction defining cells,
graphs and open strips, infinities at unbounded boundaries, coverage/disjointness, compatibility,
and whether the theorem simultaneously handles definable functions. It must decide `n = 0`, empty
families, empty input sets, and whether decomposition is of all `M^n` or only a definable subset.

Required statement mutations include removing o-minimality, removing definability of one input set,
changing finite to arbitrary families, replacing cylindrical cells by arbitrary definable pieces,
dropping partition coverage or pairwise disjointness, and moving the decomposition existential
inside the per-set quantifier. The later statement gate must demonstrate that these do not silently
survive as the canonical claim.

## Explicit exclusions

- The unary finite-union definition of o-minimality alone.
- One-dimensional interval decomposition alone when the selected source asserts all dimensions.
- Arbitrary finite definable partitions lacking the recursive cylindrical cell conditions.
- Monotonicity, definable choice, triangulation, dimension theory, or Pila-Wilkie as substitute roots.
- A cell-decomposition property assumed as a typeclass or structure field rather than proved.
- The untrusted `已验证` label, an adjacent theorem, or API elaboration as machine proof evidence.
