# THM-M-0587 rev-5.6 intake

This directory is the `planned` intake dossier for Smale's smooth h-cobordism theorem. The
repository supplies only the gloss `h-配边与微分同胚` ("h-cobordism and diffeomorphism"), an
attribution to Stephen Smale, and the year 1962. That wording omits the dimension convention,
compactness, boundary decomposition, simple-connectivity, and the relative form of the
diffeomorphism.

The dossier therefore records the standard simply connected high-dimensional smooth theorem as
a provisional claim family, not as a frozen statement. The next phase must select and inspect a
pinpointed primary source before choosing between `dim W >= 6` and the equivalent boundary
dimension convention, and before fixing whether the product diffeomorphism is relative to one or
both boundary identifications.

The root vector is conservatively `[H3, M4, R4]`. There is no accepted proof state, canonical Lean
expression, audit completion, or theorem completion. `scope-map.md`,
`source-statement-crosswalk.md`, and `task-dag.json` delimit the downstream work; `validation.md`
records the intake checks.
