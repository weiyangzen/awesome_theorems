# THM-M-1559 rev-5.6 intake

This directory is the `planned` intake for the Riemann-Hilbert problem. The repository's source
phrase, "an analytic problem for integrable systems," does not determine one proposition. This
intake narrows the historical core to realizing prescribed monodromy by a regular-singular complex
linear differential system on the Riemann sphere, while keeping the exact positive, restricted, or
counterexample formulation open for primary-source inspection.

That distinction is essential: the unrestricted classical existence formulation is not a theorem
that may simply be asserted. The provisional root vector is `[H3, M4, R4]`. No exact Lean target,
source fidelity, machine proof, audit completion, or theorem completion is claimed.

The scope map, source crosswalk, and task DAG record the downstream decisions. Intake-only checks
and their results are recorded in `validation.md`.
