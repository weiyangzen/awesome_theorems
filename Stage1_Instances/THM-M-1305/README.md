# THM-M-1305 rev-5.6 intake

This directory is the `planned` intake for the catalog label "Alinhac theorem." The upstream
metadata describes singularities of nonlinear hyperbolic equations and gives 1986, but it does not
identify a publication, theorem number, equation, dimension, data class, or conclusion. Those data
are insufficient to select one of Alinhac's several blow-up and singularity results without
substituting a theorem.

Accordingly, this intake freezes the catalog claim and its ambiguity, rather than inventing a
formal statement. The provisional root vector is `[H3, M4, R4]`. No canonical Lean target, source
fidelity, proof closure, audit completion, or theorem completion is claimed. The scope map and
source crosswalk state the exact identification work required by the statement phase.
