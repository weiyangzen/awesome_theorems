# Scope map

## Received boundary

The repository supplies three topic fragments:

- an object name: linear-bounded automaton;
- a language-family gloss: context-sensitive languages;
- an unsupported Ginsburg/Greibach, 1963 attribution.

These fragments do not determine whether the root is a model definition, a one-way inclusion, an
equivalence, a closure theorem, or an expository topic. Intake therefore freezes the ambiguity
rather than choosing the familiar CSL/LBA equivalence on the catalog's behalf.

## Proposition-changing decisions

Before the statement phase can begin, an immutable source and accountable review must decide:

1. whether the intended conclusion is deterministic LBA acceptance implies type-1 generation,
   nondeterministic LBA acceptance is equivalent to context-sensitive generation, a language
   closure property, or something else;
2. deterministic versus nondeterministic transition semantics and existential versus unique runs;
3. the LBA tape convention: exactly the input cells, endmarkers, a constant multiple of input
   length, or another checked-equivalent bound;
4. one-tape versus multitape storage, alphabet/blank conventions, head motion, initial and final
   configurations, and acceptance by state, tape exit, or halting;
5. type-1/context-sensitive grammar syntax, noncontracting versus context-sensitive productions,
   start-symbol restrictions, terminal/nonterminal disjointness, and derivation semantics;
6. treatment of the empty word, empty language, empty alphabet, zero-length inputs, and whether a
   grammar may use a special start-to-empty rule;
7. ordered binders over alphabets, languages, machines, grammars, encodings, and any finiteness or
   decidable-equality assumptions;
8. equality of languages versus two inclusions, and the checked transports between source and
   Lean representations.

## Candidate roots not credited

- **Landweber direction:** every language accepted by a deterministic LBA is generated by a type-1
  grammar. This is a proposition, but it is only one direction and the repository does not select it.
- **Kuroda equivalence:** a language is context-sensitive iff it is accepted by some
  nondeterministic LBA. This best matches the separate CSL/LBA row, but adopting it here requires an
  explicit correction and ownership decision.
- **Object formalization:** define an LBA and its operational semantics. A definition is not the
  theorem promised by a theorem-execution slot.

## Explicit exclusions

- `THM-C-0152` / the separate CSL-LBA equivalence as an automatic replacement or source of credit;
- deterministic and nondeterministic equivalence claims treated as interchangeable;
- the unrestricted Turing-machine, finite automaton, pushdown automaton, or ordinary computability
  theorems as substitutes for a space-bounded language theorem;
- CSL closure under complement, the Immerman-Szelepcsenyi theorem, the Chomsky hierarchy, or a
  context-free-language result;
- one fixed machine, grammar, alphabet, input length, or finite computation in place of a language
  class theorem;
- a structure whose fields assume the desired language equivalence and a projection of that field;
- the catalog's `verified` label, an API probe, or a source citation used as proof evidence.

No canonical mathematical statement, Lean expression, alternate encoding, degenerate-case
exclusion, obligation registry, or discovery cutoff is frozen at intake.
