# THM-M-0601 rev-5.6 intake

This directory is the `planned` intake dossier for the handle decomposition theorem. It freezes the
repository phrase as the classical smooth-manifold theorem: a compact smooth manifold, with the
boundary convention still to be selected from a pinpoint source, admits a finite decomposition by
handles. The relative and noncompact variants are recorded as alternatives, not silently included.

The Stage0 phrase "manifolds have handle decompositions" does not specify compactness, boundary
behavior, smoothness, finiteness, or the meaning of decomposition. Those choices are mathematically
material. Consequently the canonical Lean expression remains open for the statement phase. No
abstract package containing a decomposition will be accepted as a substitute for constructing one.

The provisional root vector is `[H2, M4, R4]`. This intake claims neither an elaborated theorem nor
source, audit, proof, or release closure. The scope map, source crosswalk, and open task DAG define
the downstream work; `validation.md` records the checks actually run.
