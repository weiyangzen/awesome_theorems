# THM-M-1531 rev-5.6 intake

This directory is the `planned` intake dossier for the Higgs mechanism. The human scope is the
classical gauge-theory claim that, in a specified gauge-invariant scalar-field model with a
symmetry-breaking vacuum, expansion about that vacuum yields a proper unbroken stabilizer and
mass terms for gauge-field directions outside it.

This is not yet a single source-faithful mathematical theorem. The model, regularity, gauge group,
representation, potential, vacuum orbit, and precise mass conclusion must be fixed from an
inspected primary source before a canonical Lean target can be frozen. The legacy Lean module is
discovery input only: its `HiggsMechanismData` assumes the vacuum-breaking and nonzero-mass
conclusions as fields, so its wrapper receives no statement or proof credit.

The provisional root vector is `[H3, M4, R4]`. No exact Lean statement, source fidelity, proof,
audit completion, or theorem completion is claimed. `scope-map.md`,
`source-statement-crosswalk.md`, and `task-dag.json` record the downstream decisions.
