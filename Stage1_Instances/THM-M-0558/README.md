# THM-M-0558 rev-5.6 intake

This directory is the `planned` intake for the first (absolute) Hurewicz theorem. The selected root
is the `n >= 2` connectivity theorem: vanishing lower homotopy groups entails vanishing lower
reduced integral homology, and the first potentially nonzero Hurewicz map is an isomorphism.

The Stage0 phrase only says "the relation between homotopy and homology groups." It does not fix a
unique theorem. This intake therefore records the standard first-Hurewicz interpretation and keeps
the exact source assumptions and Lean expression open for the statement phase. The `n = 1`
abelianization clause, relative Hurewicz theorem, and homology-equivalence variants receive no root
credit.

The provisional root vector is `[H1, M4, R4]`. There is no accepted proof state, elaborated target,
audit completion, or theorem completion. The scope map, crosswalk, and task DAG are the handoff.
