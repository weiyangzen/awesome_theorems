# THM-M-1540 rev-5.6 intake

This directory is the `planned` intake for Penrose twistor theory. The source label "a twistor
description of spacetime" names a research framework rather than a unique theorem. The intake
therefore freezes the intended scope as the classical incidence correspondence between complexified
compactified Minkowski spacetime and projective twistor lines, while leaving the exact theorem,
reality conditions, and conventions to the statement phase.

No experimental or physical claim is treated as a Lean theorem. No canonical Lean expression or
proof has been accepted. The provisional root vector is `[H3, M4, R4]`; audit completion and theorem
completion are both false. The scope map, source crosswalk, and open task DAG record the exact work
needed to turn the named theory into one non-broadened mathematical proposition.
