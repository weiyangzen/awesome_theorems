# THM-M-0762 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
`上下文无关语言的性质` ("properties of context-free languages"). The complete catalog claim is
only `CFL的闭包性质` ("closure properties of CFLs"), with collective attribution and the period
"twentieth century". It supplies no bibliography, definition, quantified proposition, operation
list, hypotheses, proof, or formal artifact. The metadata label `已验证` is untrusted and carries
no human-source or machine-proof credit.

"Closure properties" names a family, not one theorem. Context-free languages are classically
closed under operations including finite union, concatenation, Kleene star, reversal, homomorphism,
inverse homomorphism, and intersection with a regular language, but are not closed under arbitrary
intersection or complement. Selecting one member, asserting a conjunction of an unstated list, or
silently including a false closure claim would change the received target.

Pinned mathlib provides the formal-language and context-free-grammar substrate and a direct theorem
`Language.IsContextFree.reverse` for reversal closure. The bounded Lean probe confirms those APIs
and reports that theorem's axioms. This is useful discovery evidence only: the repository source
does not select reversal, and the intake does not transport any pinned declaration to a canonical
root or credit its proof body.

The intake therefore freezes the ambiguity and scope boundary rather than a proposition. Its
provisional root vector is `[H5, M3, R4]`: `H5` says this catalog target is not yet a stable
truth-valued proposition; `M3` records exact-topic definitions and a checked theorem interface for
one unselected branch, with no canonical-root or proof credit; `R4` records the absence of a
source-faithful proof reconstruction. The lifecycle remains `planned`, all downstream tasks remain open, and neither
audit completion nor theorem completion is claimed.
