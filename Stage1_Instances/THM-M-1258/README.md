# THM-M-1258 rev-5.6 intake

This directory is the `planned` intake for the theorem commonly called Hormander's bracket
condition/theorem for sums of squares. The repository phrase is too short to distinguish the
hypoellipticity theorem from a quantitative subelliptic estimate, so this intake preserves both
possibilities and makes selection from the 1967 source the first statement-phase task.

No canonical Lean expression or proof is claimed. The provisional root vector is `[H2, M4, R4]`;
the source theorem, analytic setting, operator convention, and exact conclusion remain open.
