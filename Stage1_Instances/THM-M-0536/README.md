# THM-M-0536 rev-5.6 intake

This directory is the `planned` intake for homotopy invariance of homology. The repository source
phrase is scoped to the claim that homotopy equivalent spaces have isomorphic homology groups. It
does not cover the unrelated homotopy invariance of homotopy groups, cohomology, or arbitrary
homotopy-invariant functors.

The source phrase does not specify the homology theory, coefficients, grading, or whether the
result is the functorial isomorphism induced by a chosen homotopy equivalence. Those decisions are
deliberately left for the statement phase and prevent an exact formal target at intake. The
provisional root vector is `[H1, M4, R4]`; no statement, proof, audit, or theorem-completion credit
is claimed.

The scope map, source-statement crosswalk, and open task DAG define the downstream work. Exact
intake checks and their results are recorded in `validation.md`.
