# THM-M-0458 rev-5.6 intake

This directory is the `planned` intake for the target labelled "Arakelov-Zhang inequality". The
repository's only supplied gloss, "height inequality for arithmetic surfaces", is not enough to
select a unique published inequality: several Arakelov-theoretic height and intersection
inequalities are associated with Zhang. Accordingly this intake freezes the subject and the
non-substitution boundary, but leaves the exact source theorem and formula open.

No canonical Lean expression or proof is claimed. The provisional root vector is `[H3, M4, R4]`.
The source crosswalk and scope map identify the ambiguity that the statement phase must resolve.
