# Scope map

## Candidate mathematical surface

| Surface | Candidate role | Unresolved choice |
|---|---|---|
| Index | an ordinal or a particular finite/countable ordinal | length and internal representation |
| Stages | forcing notions or names for forcing notions over prior extensions | ground-model versus name-valued presentation |
| Successor step | a two-step iteration of the current forcing with the next forcing name | order convention, top conditions, and equivalence notion |
| Limit step | conditions assembled from earlier stages | finite, countable, revised countable, full, or mixed support |
| Coherence | restriction/projection maps and compatibility between stages | exact iteration-system axioms |
| Ground model | a coded or external model of a specified fragment of set theory | theory, transitivity, countability, and metatheory |
| Conclusion | definition, factorization/density equivalence, generic-extension identity, chain-condition preservation, properness preservation, or another iteration theorem | no conclusion is selected by the source |
| Lean surface | an exact proposition using pinned set-theory/forcing APIs | no canonical module or expression is selected |

## Boundaries

The eventual target must state the support policy at every limit stage, all stage hypotheses, the
forcing-order convention, the model-theoretic setting, and one exact conclusion. It must cover or
explicitly exclude zero-length and successor-only iterations, limit ordinals of different
cofinalities, trivial stages, and empty supports.

Product forcing, a single two-step forcing construction, class forcing, Boolean iterations, and a
particular consistency result are not equivalent substitutes. Likewise, a preservation theorem
for ccc, properness, cardinality, or a forcing axiom cannot be selected merely because it uses an
iteration. The metadata label `已验证` is not evidence for any of these readings.
