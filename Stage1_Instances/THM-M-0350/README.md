# THM-M-0350 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository title
"Hilbert transform boundedness" and its gloss "the Hilbert transform is bounded on `L^p`."
The intended theorem family is the M. Riesz strong-type result for `1 < p < infinity`, but the
repository metadata does not choose the real-line or periodic transform, a normalization, a dense
initial domain, or a precise meaning of the principal value.

Those choices are mathematically material. This intake therefore records the theorem family and
its scope boundary without inventing an exact proposition. The root remains `[H1, M4, R4]`. A
narrow probe against the pinned Lean environment confirms that `Lp`, continuous linear maps, and
Fourier multipliers on Schwartz functions and tempered distributions are available. It does not
define the Hilbert transform, establish an `Lp` extension, or provide proof credit.

The exact source and formal statement gates remain open. No accepted proof state, audit completion,
or theorem completion is claimed.
