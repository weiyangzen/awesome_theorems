# THM-M-0386 rev-5.6 intake

This directory is the fail-closed `planned` intake dossier for the repository label
"Elekes-Szabo theorem". The repository supplies only the gloss "values of a polynomial on grid
points", the authors' names, and the year 2012. That wording does not identify a proposition.

The name normally refers to a structural theorem about algebraic surfaces containing many points
of a Cartesian product. Closely related quantitative incidence bounds and later refinements differ
in their field, irreducibility and degree assumptions, exceptional loci, exponents, constants, and
the precise group-like alternative. Selecting one of them from the repository gloss would silently
substitute a theorem.

This intake therefore freezes the intended theorem family and the ambiguity boundary, not an exact
claim. The root remains `[H3, M4, R4]`. A narrow pinned Lean probe checks only that multivariate
polynomials, evaluation, finite sets, and Cartesian products are available as possible encoding
ingredients. It is not a statement or proof. Exact checks are recorded in `validation.md`.
