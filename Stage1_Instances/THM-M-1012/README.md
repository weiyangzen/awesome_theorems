# THM-M-1012 rev-5.6 intake

This directory is the `planned` intake for the Levy continuity theorem. It freezes the intended
claim as the known-limit equivalence between weak convergence of probability measures and
pointwise convergence of characteristic functions on a finite-dimensional real inner product
space.

The stronger existence formulation, which constructs a limiting measure from an arbitrary
pointwise limit continuous at zero, is explicitly outside this frozen claim. The legacy module and
its mathlib wrapper are discovery evidence only under the uniform L0 rework rule. The provisional
root vector is `[H2, M4, R4]`; exact elaboration, audit completion, and theorem completion remain
open.

`scope-map.md`, `source-statement-crosswalk.md`, and `task-dag.json` define the downstream boundary.
The exact intake checks are recorded in `validation.md`.
