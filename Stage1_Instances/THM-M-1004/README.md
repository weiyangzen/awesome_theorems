# THM-M-1004 rev-5.6 intake

This directory is the `planned` intake for the optional stopping theorem. It freezes the intended
claim to the bounded, discrete-time, real-valued martingale version: for ordered bounded stopping
times `tau <= pi`, the stopped values have equal expectations.

The legacy Lean module is discovery input only. Although it contains a plausible statement and
wrappers, rev-5.6 requires the statement and later proof evidence to be re-audited. This intake
claims `[H2, M4, R4]`, not an exact formal statement, audit completion, or theorem completion.

The scope map, source crosswalk, and open task DAG record the decisions and remaining gates. Exact
intake validation is recorded in `validation.md`.
