# Scope map

## Preserved source scope

- Subject: harmonic functions.
- Claimed relation: their derivatives admit a bound.
- Context: differential equations / partial differential equations.
- Attribution and date in the repository: many mathematicians, twentieth century.

## Decisions required before statement freeze

The statement phase must identify a primary source and freeze the Euclidean domain and dimension,
scalar field, harmonicity and regularity predicates, derivative order (the title suggests first
derivatives, while the source wording permits higher derivatives), pointwise or norm conclusion,
interior region and boundary-distance assumptions, controlling function norm, scaling powers, and
constant dependencies. It must also address zero radius, empty domains, dimension zero, constant
functions, and other degenerate cases admitted by the selected formulation.

## Explicit exclusions

- A Cauchy estimate for holomorphic functions (`THM-M-1145`) substituted without a checked
  harmonic/holomorphic transport and source justification.
- Gradient estimates for eigenfunctions, heat-equation solutions, manifolds, or general elliptic
  operators chosen merely because an API is available.
- Harnack comparison, mean-value, maximum-principle, or Liouville theorems as replacements.
- Treating the repository status `已验证` as source or machine-proof evidence.
