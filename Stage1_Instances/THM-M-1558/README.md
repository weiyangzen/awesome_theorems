# THM-M-1558 rev-5.6 intake

This directory is the `planned` intake for the Ablowitz-Kaup-Newell-Segur (AKNS) system. The
repository source gives only the phrase "a unified framework for integrable systems". That phrase
names a method or family of systems, not a proposition with fixed quantifiers and a conclusion.

The intake therefore freezes the literal source wording and the likely zero-curvature/Lax
compatibility claim as a provisional scope, while leaving the exact source theorem and Lean target
open. In particular, it does not silently choose one AKNS flow, an inverse-scattering existence
theorem, or a claim that every integrable PDE belongs to the AKNS hierarchy.

The provisional root vector is `[H3, M4, R4]`. There is no accepted proof state, canonical Lean
expression, audit completion, or theorem completion. The scope map, source crosswalk, and open task
DAG state exactly what the statement phase must resolve. Intake validation is in `validation.md`.
