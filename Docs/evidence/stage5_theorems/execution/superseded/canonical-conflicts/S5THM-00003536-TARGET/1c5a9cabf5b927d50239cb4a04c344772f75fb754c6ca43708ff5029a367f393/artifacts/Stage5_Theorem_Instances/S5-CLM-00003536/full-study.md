# Full study — Furstenberg's ×2, ×3 orbit theorem

The frozen target says that for every irrational real `ξ`, the image in
`ℝ/ℤ` of the two-parameter positive semigroup orbit
`ξ · 2^m · 3^n` is dense.  Its key mathematical content is not an algebraic
normalization but Furstenberg's rigidity/density result for the multiplicative
semigroup generated by 2 and 3.

The two generators are multiplicatively independent: an equality `2^a=3^b`
with nonnegative exponents forces both exponents to be zero.  Furstenberg's
theorem exploits this independence for the commuting circle endomorphisms
`T₂(x)=2x` and `T₃(x)=3x`.  A closed invariant set for both maps is either
finite/rational in the exceptional case or the whole circle.  An irrational
starting point cannot have a finite orbit, so the closure of its semigroup
orbit is the whole circle.

nonnegative to positive exponents applies the continuous surjective map

one), so density is preserved.  The target set-builder then spells out the
