# Proof outline

1. Write the weighting equation as `Z(t)w(t)=1`.
2. Subtract a base row from every other row and divide those differences by
   `t`; the coefficient matrix tends to the normalization-plus-distance-row-
   differences system.
3. Use the unit determinant of `D` to prove that limiting system nonsingular.
4. A gauging solves that limiting system, so continuity of finite-dimensional
   matrix inversion gives `w(t) → g`.
5. In the other direction, pass any microscopic limit through the same row
   equations to obtain a gauging.
6. Compose the two implications and audit the bidirectional identity with the
   frozen provider type.
