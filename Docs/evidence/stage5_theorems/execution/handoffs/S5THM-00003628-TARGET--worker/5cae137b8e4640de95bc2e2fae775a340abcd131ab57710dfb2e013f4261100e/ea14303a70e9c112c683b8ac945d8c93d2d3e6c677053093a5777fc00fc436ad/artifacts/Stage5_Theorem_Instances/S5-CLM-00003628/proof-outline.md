# Proof outline: Erdős 1057 upper bound

## Root

The root proposition is the frozen upper-bound variant: there is a positive
constant `c` such that, eventually at `atTop`, the Carmichael counting
function is bounded by the stated exponential envelope.

## Typed composition

1. Bind the exact provider declaration and its source byte interval.
2. Preserve the positive witness required by the existential conclusion.
3. Compose the eventual estimate with the logarithmic/exponential envelope.
4. Package the result as the target proposition and transport it in both
   directions through the claim-owned surface.

downstream uses, and trust boundary are enumerated in `proof-units.json`; this
