# Stage5 theorem claim fixtures

This directory is an immutable BOOT-owned portability fixture root for the
Stage5 theorem claim and execution-controller validation suite.  Fixture
repositories below intentionally differ in repository name, Blueprint path,
item prefix, implementation language, validator command, and route policy.

They are data-only inputs.  BOOT validation must never execute their commands
or treat either fixture as the canonical Awesome Theorems repository.
